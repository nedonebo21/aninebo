# Animebo

Пет-проект для практики Next.js, TanStack Query и работы с внешними API. Фронтенд для просмотра аниме

## Стек
- Next.js 16 + React 19 + TypeScript
- TanStack Query (React Query) + Axios
- Tailwind CSS 4 + Radix UI (Shadcn)
- React Hook Form + Zod
- Next Themes (тёмная/светлая тема)

## Что делал
- Интеграция с публичным API (AniLibria / AnimeGo)
- Список аниме, жанры, описания, плеер
- Настройка кэширования и работы с состоянием запросов (TanStack Query)
- Валидация форм и капча (RHF + Zod, hCaptcha)
- Настройка UI-компонентов на базе Radix UI и Tailwind
